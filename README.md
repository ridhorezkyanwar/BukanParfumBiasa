# BukanParfumBiasa
👃 BukanParfumBiasa - Ren Parfume Landing Page
Balik lagi sama project gue gess! Ini adalah Landing Page Eksklusif buat brand Ren Parfume. Targetnya simpel: Bikin calon buyer ngerasa kalau parfum ini bukan sekadar wangi, tapi jati diri.
Project ini dibangun pake stack modern yang sat-set tapi powerfull. No debat!
🚀 Tech Stack
Framework: React.js (Vite) - Biar development-nya kenceng gak pake lama.
Styling: Tailwind CSS - Full Custom Earth Tone palette (Flat Design).
CMS: Contentful - Headless CMS biar urusan update produk gak perlu bongkar kode.
Icons: FontAwesome - Biar visualnya clean dan gak bocah.
Methodology: AIDA (Attention, Interest, Desire, Action) Marketing Framework.
🛠️ Fitur Utama
Dynamic Product List: Data parfum (deskripsi, harga, kategori) ditarik langsung dari Contentful API.
WhatsApp Integration: CTA yang langsung nge-link ke WhatsApp Business dengan prefill text otomatis.
Responsive Design: Cakep di layar monitor, tetep seksi di layar HP.
Flat Design Aesthetics: Main di tone coklat premium buat kesan organik dan mahal
